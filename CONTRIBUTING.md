# Contributing to C++ Atlas

Спасибо за желание улучшить C++ Atlas.

## Что можно улучшать

Приветствуются:

- исправления ошибок в описании C++;
- новые навыки и практические задания;
- улучшение зависимостей между узлами;
- улучшения UI/UX;
- исправления мобильной версии;
- улучшения доступности;
- новые полезные источники.

## Как предложить изменение

1. Создайте Issue и кратко опишите проблему или предложение.
2. Сделайте Fork репозитория.
3. Создайте отдельную ветку.
4. Внесите изменения.
5. Проверьте, что `index.html` открывается без ошибок.
6. Создайте Pull Request.

## Изменения контента

Основной структурированный контент находится в:

```text
cpp-atlas-content.json
```

При добавлении навыка старайтесь указывать:

- уникальный `id`;
- название;
- stage;
- tier;
- difficulty;
- что это;
- что нужно знать;
- зачем тема нужна;
- практическое задание;
- prerequisites.

## Стиль

Главная цель проекта — делать roadmap понятной и практически полезной.

Избегайте добавления темы только ради увеличения количества пунктов. Каждый узел должен отвечать хотя бы на один вопрос:

- Что нужно знать?
- Зачем это нужно?
- Когда это изучать?
- Как проверить, что тема освоена?
