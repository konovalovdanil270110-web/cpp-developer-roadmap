## 🚀 Запуск

Проект не требует сборки, Node.js или дополнительных зависимостей.

### Вариант 1 — просто открыть

Скачайте репозиторий и откройте:

```text
index.html
```

в браузере.

### Вариант 2 — GitHub Pages

1. Откройте `Settings` репозитория.
2. Перейдите в `Pages`.
3. В `Build and deployment` выберите `Deploy from a branch`.
4. Выберите ветку `main`.
5. Выберите папку `/(root)`.
6. Нажмите `Save`.

После публикации GitHub покажет ссылку на сайт.

## 🧠 Основная идея

Roadmap построена не как строгая последовательность:

```text
Beginner → Junior → Middle → Senior
```

а как сеть связанных направлений:

```text
                    ┌─ STL
                    ├─ Algorithms
C++ Core ───────────┼─ Memory / RAII
                    ├─ OOP
                    ├─ Tooling
                    ├─ Concurrency
                    └─ Systems / Architecture
```

Навыки имеют зависимости, сложность и принадлежность к профессиональному уровню.

## 🏁 Уровни

Карта включает checkpoint'ы развития:

- C++ Beginner
- Beginner
- Junior
- Junior+
- Middle
- Middle+
- Senior

Checkpoint — это не просто название уровня. В нём собраны знания, hard skills, практические требования и примеры проектов, которыми можно подтвердить уровень.

## 📁 Структура проекта

```text
cpp-atlas/
├── index.html                 # интерактивное приложение
├── cpp-atlas-content.json     # структурированный контент roadmap
├── README.md
├── CONTRIBUTING.md
└── .nojekyll
```

`index.html` сейчас является самостоятельной версией приложения и содержит данные карты внутри себя.  
`cpp-atlas-content.json` оставлен отдельно как удобный исходник контента для редактирования и дальнейшего развития проекта.
